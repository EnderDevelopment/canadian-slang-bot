# CanadianSlangBot

CanadianSlangBot is a Discord bot designed to engage users with Canadian slang. When pinged, the bot responds with phrases like "Slime gyal, dem 2 2a my word gerbet and hafasz!" to add a fun and interactive element to your Discord server.

## Install

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/CanadianSlangBot.git
   ```
2. Navigate to the project directory:
   ```
   cd CanadianSlangBot
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Create a `.env` file in the project directory and add your Discord bot token:
   ```
   DISCORD_TOKEN=your_discord_bot_token_here
   ```

## Use

1. Run the bot:
   ```
   python bot.py
   ```
2. Invite the bot to your Discord server using the OAuth2 URL generated by the Discord Developer Portal.
3. Ping the bot in any channel to receive a response in Canadian slang.
